# A-Cross-Framework-Evaluation-Using-LangGraph-AutoGen-and-CrewAI
Multi-Agent Literature Review Framework Evaluation

This repository contains the complete experimental setup and results for the paper
“A Comparative Evaluation of Agentic Orchestration Frameworks for Automated Literature Review and Research Drafting.”
Experimental Details
Frameworks evaluated: LangGraph, CrewAI, AutoGen
Number of topics per framework: 3
Total runs: 9
Evaluation method: LLM-as-a-Judge with Opik-based tracking
